# Вопросы holo-1

Выбран самый безопасный вариант, работа не останавливалась.

1. **Права `holo.view.<id>` и `perm:узел`.** В ядре прав нет (только OP). Сейчас по умолчанию право есть только у OP;
   модуль прав (если появится) подставляет свою проверку через `HoloApi.permissions((player, node) -> …)`.
   Нужно ли сделать простые права в самом holo (список ников на узел в config.yml)?
2. **Консольные команды у голограмм из кода.** `HoloApi.put` не ставит `creatorOp` сам — модуль-владелец решает
   (`h.creatorOp = true`, если ему можно). Так безопаснее; если нужно иначе — скажите.
3. **Несохранённые правки при выходе из редактора** отбрасываются после второго Esc (первый — предупреждение).
   Альтернатива — держать черновики до выхода с сервера. Оставил отбрасывание: на сервере всегда то, что видят все.
4. **Колёсико в режиме «двигать»**: в ClientContext нет крючка колёсика, поэтому расстояние меняется по смене слота
   хотбара (слот сразу возвращается). Если нужно «чисто» — нужен крючок ядра мода (`onScroll`), это 0.84.0.
