## Тематика (обязательно посмотреть)
Старый HUD кораблей: `client/modules/ships/.../ShipHud.java`. Взять оттуда **стиль и технику**:
- элементы рисуются **картинками в размер экрана в пикселях экрана** (Canvas со сглаживанием и мягкой тенью,
  без растягивания — чётко на любом масштабе GUI), статичные слои рисуются один раз, меняющиеся — только когда
  изменились (и не чаще 60 раз/с);
- палитра: светло-серый `0xD9E2EE`, белый, тёмный `0x05080F`, янтарный `0xFFC46B` для форсажа/предупреждений;
  тонкие линии, мягкая тень, без ванильных текстур и без «плашек из Minecraft».
Общий код рисования можно вынести, но старый модуль `ships` не менять.

## HUD пилота — по мотивам War Thunder (авиа, аркадный режим)
Минимализм: тонкие линии и цифры прямо поверх мира, плашки — только где нужно читать много.
- **Центр:** прицел орудия (кружок/ромб с точкой), маркер носа (куда смотрит корабль — «птичка»/крестик),
  если прицел и нос расходятся — видно оба. **Маркер попадания** (короткий крестик-вспышка при попадании, другой
  цвет при убийстве). Перезарядка орудия — тонкая дуга вокруг прицела.
- **Сверху:** лента компаса с курсом (риски, стороны света / градусы, метка текущего курса) — как в WT.
- **Слева:** лента/шкала скорости (бл/с) с числом в рамке-указателе; «тяга» в % и метка ФОРСАЖ (янтарным).
- **Справа:** лента высоты (Y мира) с числом; лесенка тангажа (pitch ladder) у центра — как в старом `ShipHud`.
- **Слева внизу:** силуэт корабля (контур модели сверху — можно отрисовать из треугольников модели `Kind.shape`
  проекцией на плоскость XZ) — в будущем для повреждений; сейчас под ним **топливо**: шкала + число + отметка цены
  варпа.
- **Справа внизу:** блок оружия (название, готовность/перезарядка) и **варп** (ГОТОВ / зарядка % / перезарядка /
  НЕТ ТОПЛ.); во время зарядки — крупная шкала у центра снизу и «R — отмена».
- **Подсказки клавиш** — мелко, внизу по центру, гаснут через ~10 с после посадки (показать снова — удержание H или
  при наведении… на твоё усмотрение, опиши).
- Сообщения сервера — по центру сверху под компасом, плавно гаснут.
- Поведение на масштабах GUI 1–4 и маленьких окнах: ничего не налезает, не обрезается.
- Ванильный HUD по-прежнему скрыт (ядро 0.79 `hideHud`).

## Меню корабля (G) — красиво, в той же тематике
Сейчас — сундук 5 рядов с ярлыками-предметами. Нужно своё окно:
- Тёмная полупрозрачная панель в стиле HUD (тонкие светлые рамки, мягкая тень), заголовок — имя корабля/вида;
  три группы с подписями: **ГРУЗ** (27, сетка 9×3), **УЛУЧШЕНИЯ** (8), **ТОПЛИВО** (4, с шкалой бака рядом);
  у слотов улучшений и топлива — бледные значки-подсказки, что туда класть; справа или снизу — сводка (бак, цена
  варпа, бонусы улучшений). Инвентарь игрока — снизу, как обычно.
- Слоты остаются **настоящими слотами** (сервер — тот же инвентарь Minestom, вся логика vessels-2 сохраняется:
  роли слотов, Shift-клик, доступ). Меняется только то, как клиент рисует это окно и где стоят слоты.
- Как это сделать — выбери сам и опиши: например, сервер помечает окно (тип/заголовок), а мод для такого окна
  рисует свой фон и переставляет координаты слотов (через `@Accessor`/хук в ядре + API для модулей; ядро →
  0.80.0). Игрок без мода/со старым модом видит обычный сундук — должно оставаться рабочим.
- Ярлыки-предметы в сундуке (стрелки «Улучшения ▸» и т.п.) в новом окне не видны (или их нет вовсе, если
  мод рисует подписи сам).
