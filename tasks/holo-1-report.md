# Отчёт holo-1: голограммы на моде + редактор

Статус: в работе. Пункты по порядку.

## 1. Модель данных и сервер (`modules/holo`) — готово
- Модель `Hologram` (страницы → строки → ряд элементов: text, item, image, bar, button, separator, spacer; действия
  cmd/console/msg/sound/tp/ui/page по ЛКМ/ПКМ у любого элемента и у самой панели), JSON — `HoloCodec` (строгий разбор).
- Файлы `module/holo/holograms.json`, `templates.json` — атомарно, битый не перезаписывается (`HoloStore`).
- Плейсхолдеры: `Placeholders` — своя частота у каждого, считается на сервере на игрока, моду только изменившееся.
- Нажатия: `ClickGuard` — карта, видимость, расстояние, элемент, условие (OP/право), задержка; консоль — только у
  голограмм OP.
- Сервис `HoloApi`, команды `/hoholo` (`HoloCommand`), протокол — `Net`.

## 2. Отрисовка (`client/modules/holo`) — готово
- `Mini` — разбор MiniMessage (цвета, стили, градиент, радуга, перенос), `Holo` — модель и темы, `Layout` — раскладка
  (ряды, перенос слов, меню из кнопок, кэш — пересчёт только при изменении данных/значений/страницы).
- `Paint` — вид: панель `0x05080F`, сканлинии (текстура с повтором — 1 квад на панель), рамка из кубиков 1/16 блока
  (уголки крупнее, янтарь у углов), мерцание, сборка из точек за 0.42 с и рассыпание при удалении, кнопки с кубиками
  по контуру (наведённая ярче и выдвинута), шкала с делениями, разделитель, точка-курсор.
- `HoloClientModule` — свои проходы (фон — обычное смешивание, кубики/свечение — «свечение» LIGHTNING, сканлинии —
  текстура), текст — `Font.drawInBatch` с матрицей, предметы — рендер предметов игры (`ItemStackRenderState`),
  картинки — `ctx.texture`. Только в дальности и в кадре, дальние первыми, координаты относительно камеры.
- Наведение — `Orient.hit` (луч от глаз, не сквозь блок), клик ЛКМ/ПКМ забирается и уходит серверу, подсказка в HUD.

## 3. Редактор — готово
- `EditorUi` (чистый код, рисует через `Gui`) + `EditorScreen` (окно игры). Открывается `/hoholo edit [id]` или **J**
  (только если сервер сказал «OP»), глядя на голограмму — сразу она.
- Слева: список всех голограмм сервера (поиск, фильтр по карте, расстояние, ПКМ — телепорт), id → «Создать», «Копия»,
  «Удалить» (повторное нажатие за 3 с — «Точно?»), «ТП».
- «Свойства»: X/Y/Z (поле + ±1/±0.1), «Сюда», «К блоку» (на стене — фиксированно, лицом от стены), «Двигать ✥»,
  поворот (режим, курс, наклон), масштаб, тема, ширина (0 — авто), отступ, прозрачность, фон/рамка/парение,
  дальность, видимость (все / OP / право `holo.view.<id>`), карта, страницы (листать, добавить, удалить, порядок),
  действия клика по панели.
- «Строки»: добавить любой тип (новой строкой или «в ряд»), чипы элементов, перетаскивание строк мышью за «≡»,
  ↑↓ строки, ◂▸ в ряду, дубль, удалить (и Delete). Поля по типу: текст с подсветкой MiniMessage, вставка
  плейсхолдера «{}» (список с сервера, с частотой) и тега «<>», размер, выравнивание; предмет — id с
  автодополнением (свои hoitems + ванильные), «Из руки», вращение; картинка — выбор файла; шкала — значение,
  максимум, подпись, цвет (палитра), ширина; кнопка — подпись, цвет, размер, ширина. У всех: подсказка, условие
  (все / OP / право), задержка, конструктор действий ЛКМ/ПКМ (тип из списка, значение с примером, порядок, удалить).
- «Шаблоны»: создать из шаблона (3 встроенных: табличка станции, меню с кнопками, информация со шкалой),
  сохранить выбранную как шаблон, удалить шаблон.
- Живой предпросмотр: правки — в черновик (`Session`), голограмма в мире меняется сразу; маленькое превью справа
  (клик по элементу — выбрать). «Сохранить» (Ctrl+S) / «Авто» (через 0.6 с после правки), Отмена/Повтор
  (Ctrl+Z / Ctrl+Y, ввод в одно поле подряд — одна отмена). Esc с несохранённым — предупреждение, второй Esc —
  выйти без сохранения.
- Перемещение в мире (`Mover`): голограмма за прицелом (на блок или на расстоянии), колёсико — расстояние,
  Shift — точно, стрелки-гизмо X/Y/Z (навести, тянуть ЛКМ), G — следовать/стоять, Enter или ПКМ — поставить,
  Backspace — отменить.
- Сервер проверяет каждую правку (OP), разбирает строго (`HoloCodec`), сохраняет и рассылает.
