# Отчёт holo-1: голограммы на моде (кубоидный космический стиль) + редактор

Ветка `ai/holo-1`. Новые модули: сервер `modules/holo` (0.1.0), клиент `client/modules/holo` (0.1.0).
**Ядро мода и ядро сервера не трогались** (версия ядра мода остаётся 0.83.0). Модули tearsmilk не трогались.

Сборка: `./gradlew build` — ок (все тесты); `cd client && gradle :core:build :modules:holo:build` — ок.
Превью PNG — `tasks/holo-1-preview/` (пересоздать: `cd client && gradle :modules:holo:test -PholoPreview=../tasks/holo-1-preview`):
- `holo-space.png` — голограмма темы space: заголовок-градиент, разделитель, предмет (заглушка-кристалл), текст с
  плейсхолдерами, шкала, ряд кнопок-меню; наведена «Магазин» (ярче, рамка-кубики выдвинута), точка-курсор;
- `holo-themes.png` — темы space / amber / danger / green; `holo-appear.png` — сборка рамки из точек (12…100 %);
- `editor-lines.png`, `editor-text.png`, `editor-properties.png` — окно редактора (вкладки «Строки» с выбранной
  кнопкой и конструктором действий, текст с подсветкой MiniMessage, «Свойства»).
В превью текст — системным шрифтом, в игре — шрифт игры; объём кубиков показан косой проекцией.

## 1. Модель данных и сервер (`modules/holo`) — сделано
- `Hologram` — id, карта, позиция, курс/наклон, режим поворота (fixed / billboard_y / billboard), масштаб, тема,
  ширина (0 — авто), отступ, фон и прозрачность, рамка, парение, дальность, видимость (all / op / perm →
  `holo.view.<id>`), страницы → строки → ряд элементов, действия клика по самой панели.
- Элементы: `text` (MiniMessage, размер 0.5–4, выравнивание), `item` (ванильный или свой `hoka:<id>` из hoitems,
  вращение, размер, подсказка), `image` (PNG из `module/holo/images/`, размер в блоках), `bar` (число/плейсхолдер,
  максимум, цвет, подпись), `button` (подпись, цвет, размер), `separator`, `spacer`. **У любого элемента** — действия
  ЛКМ/ПКМ, условие (all / op / `perm:узел`), задержка, подсказка.
- Действия: `cmd` (от игрока), `console` (только у голограмм OP), `msg` (MiniMessage-подмножество), `sound`
  («id [громкость высота]»), `tp` («x y z [курс наклон]» или «карта x y z»), `ui` (окно houi), `page`
  (next / prev / номер). В значениях работают плейсхолдеры.
- JSON (`HoloCodec`) — один формат для файла, протокола и редактора; разбор строгий (понятные ошибки).
- Файлы `module/holo/holograms.json`, `templates.json` (`HoloStore`): атомарно (tmp → rename), битый файл не
  перезаписывается (сохранение выключено до `/hoholo reload`), запись в отдельном потоке.
- Плейсхолдеры (`Placeholders`): `{player} {online} {time} {map} {x} {y} {z}` + от других модулей. Считаются на
  сервере для каждого игрока, у каждого своя частота (config.yml / при регистрации), только нужные игроку (из
  голограмм рядом), моду — только изменившиеся.
- Нажатия (`ClickGuard`): карта, видимость, расстояние (дальность + `click-reach`), элемент существует и
  кликабелен, условие, задержка (отдельно ЛКМ и ПКМ), страница совпадает; `console` отбрасывается у голограмм не-OP.
- Сервис `HoloApi` (пример ниже), команды `/hoholo` (`/holo`): `edit [id]`, `create <id>`, `remove <id>`, `list`,
  `tp <id>`, `movehere <id>`, `copy <id> <новый>`, `addline <id> <текст>`, `reload` — только OP/консоль.
- Шаблоны: 3 встроенных («табличка станции», «меню с кнопками» — 2 страницы, «информация со шкалой»), свои —
  из редактора.

## 2. Отрисовка (`client/modules/holo`) — сделано
- `Mini` — MiniMessage (цвета, `<#hex>`, b/i/u/st/obf, gradient, rainbow, br, reset, экранирование), `Layout` —
  раскладка в «точках» (40 на блок): ряды, перенос слов, ряд из одних кнопок — меню на всю ширину, кнопкам вместо
  переноса уменьшается шрифт; **кэш**: пересчёт только при смене данных / страницы / значений плейсхолдеров.
- `Paint` — вид: панель `0x05080F` с прозрачностью, блик и сканлинии (текстура с повтором — 1 квад на панель),
  рамка из кубиков 1/16 блока (светлые/голубые, уголки крупнее, янтарь у уголков), мерцание, сборка из точек за
  0.42 с, рассыпание при удалении; кнопки с кубиками по контуру, наведённая — ярче и выдвинута; шкала с делениями;
  точка-курсор. Темы — из `config.yml` сервера.
- В мире (`HoloClientModule`): свои проходы — фон (обычное смешивание), кубики и свечение («свечение»
  LIGHTNING, как плёнка станций), сканлинии (текстура); текст — `Font.drawInBatch` с матрицей (POLYGON_OFFSET);
  предметы — рендер предметов игры (`ItemStackRenderState` → `submits()`); картинки — `ctx.texture`. Только в
  дальности, отсечение по кадру, дальние первыми, координаты относительно камеры.
- **Стоимость**: голограмма «welcome» (превью) ≈ 1300 квадов (рамка 5 граней на кубик), 30 таких ≈ 40 000 —
  порядок одного чанка блоков; тысячи линий нет.
- Наведение (`Orient.hit`): луч от глаз, ближайшая панель, не сквозь блок, до 16 блоков. ЛКМ/ПКМ по кликабельному
  забирается модом (`onClick` → true, зажатая ЛКМ не ломает блок за панелью) и уходит серверу; подсказка
  элемента (или имя предмета) — под прицелом.

## 3. Редактор — сделано
`EditorUi` (чистый код, рисует через `Gui` — тот же код в игре и в PNG) + `EditorScreen`. Открыть:
`/hoholo edit [id]` или **J** глядя на голограмму (J работает, только если сервер сказал моду «OP»).
- **Список**: все голограммы сервера (поиск, фильтр по карте, расстояние; ПКМ — телепорт), «Создать» по id,
  «Копия» (перед игроком), «Удалить» (второе нажатие за 3 с — «Точно?»), «ТП».
- **Свойства**: X/Y/Z (поле + −1/−.1/+.1/+1), «Сюда», «К блоку» (на стене — фиксированно, лицом от стены),
  «Двигать ✥»; режим поворота, курс, наклон, масштаб, тема, ширина, отступ, прозрачность, фон/рамка/парение,
  дальность, видимость, карта; страницы (листать, + / −, порядок); действия клика по панели.
- **Строки**: добавить любой тип новой строкой или «в ряд», чипы элементов, перетаскивание строк мышью за «≡»,
  ↑↓, ◂▸ (порядок в ряду), «Дубль», «Удалить» (и Delete). Поля по типу: текст с подсветкой тегов и
  плейсхолдеров, «{}» — вставить плейсхолдер из списка сервера (с частотой), «<>» — тег; размер, выравнивание;
  предмет — id с автодополнением (свои hoitems + ванильные), «Из руки», вращение; картинка — выбор файла;
  шкала — значение/максимум/подпись/цвет (палитра)/ширина; кнопка — подпись/цвет/размер/ширина. Общие: подсказка,
  условие, задержка и **конструктор действий** (ЛКМ/ПКМ, тип из списка, значение с примером, ↑↓, ✕, «+ действие»).
- **Шаблоны**: создать из шаблона, сохранить выбранную как шаблон, удалить шаблон (с подтверждением).
- **Живой предпросмотр**: правки в черновик (`Session`) — голограмма в мире меняется сразу (видит только редактор),
  маленькое превью справа (клик по элементу — выбрать). «Сохранить» (Ctrl+S) или «Авто» (через 0.6 с после
  правки). **Отмена/Повтор** — Ctrl+Z / Ctrl+Y (ввод в одно поле подряд — одна отмена). Esc с несохранённым —
  предупреждение, второй Esc — выйти без сохранения.
- **Двигать в мире** (`Mover`): за прицелом (на блок или на расстоянии), колёсико — расстояние, Shift — точно,
  стрелки-гизмо X/Y/Z (навести и тянуть ЛКМ), G — следовать/стоять, Enter или ПКМ — поставить, Backspace — отмена.
- Сервер проверяет каждую правку: OP, строгий разбор; отказ — черновик снова «не сохранён».

## 4. Протокол — сделано
Канал клиентского модуля `holo`, полное описание — `modules/holo/src/main/java/ink/hoka/odyssey/holo/Net.java`.
Сервер → мод: HELLO (OP, карта, темы), SET (полная голограмма + страница + предметы в сетевом виде игры),
REMOVE (рассыпаться / тихо), CLEAR (смена карты), VALUES (только изменившиеся плейсхолдеры), PAGE, INFO (для
редактора), EDIT, RESULT. Мод → сервер: CLICK, SAVE, DELETE, TP, TPL_SAVE, TPL_DELETE, INFO_REQ.
Голограмма уходит моду, когда игрок ближе `range + send-margin`, убирается дальше `range + 2×send-margin`;
при изменении — SET только этой голограммы тем, у кого она есть. **Игрок без мода голограмм не видит** (ванильного
запасного вида нет — по задаче).

## 5. Тесты
- Сервер `HoloTest`: JSON всех типов и страниц (разбор → запись → разбор), строгие ошибки, файл (атомарно,
  временные не пишутся, битый не трогается, дубли id), шаблоны, плейсхолдеры (подстановка, частота, только
  изменения, забыть/снять владельца), нажатия (видимость, карта, расстояние, элемент, условие, задержка ЛКМ/ПКМ,
  консоль только у OP, клик по панели), MiniLite.
- Мод `HoloLogicTest`: MiniMessage, раскладка (размеры строк/рядов, меню, шкала, ничего не вылезает за ширину,
  перенос длинного текста и слова), страницы, луч в панель (fixed / billboard), сессия (отмена/повтор, склейка
  ввода, создание↔отмена, отказ сервера), операции редактора (добавить, в ряд, перенос, удалить + отмена).
  `PreviewTest` — PNG и оценка квадов.

## Как выложить
1. `modules/holo/build/libs/holo.jar` → `module/holo.jar`, затем `homodule reload holo` (или рестарт).
2. `client/modules/holo/build/libs/holo.jar` → `module/clientmods/jars/holo.jar` (как остальные клиентские модули),
   `hoclient reload` — у игроков подтянется без перезахода. Ядро мода обновлять не нужно.
3. По желанию: картинки — `module/holo/images/*.png`, затем `/hoholo reload`.

## Как проверить в игре
1. **Создать**: OP, `/hoholo create test` — перед вами панель (рамка собирается из кубиков). Отойдите дальше 32 блоков (дальность по умолчанию)
   и вернитесь — исчезает и появляется снова.
2. **Редактор**: посмотрите на панель и нажмите **J** (или `/hoholo edit test`). «Строки» → «Кнопка»; справа и в
   мире она появилась сразу. Измените подпись — видно вживую. Ctrl+Z / Ctrl+Y — отмена/повтор. «Сохранить».
3. **Кнопка с командой**: у кнопки в «Действия» → тип «команда игрока», значение `spawn` (или любая ваша команда).
   Сохранить, закрыть, навести на кнопку (подсветка, точка-курсор), ЛКМ — команда выполнилась. Тип «команда
   консоли» — `say {player} нажал` — работает (голограмму правил OP). Задержка 40 — второе нажатие сразу не срабатывает.
4. **Плейсхолдер**: строка «Текст» → «{}» → `{time}` и `{x}` — время меняется раз в секунду, `{x}` — при ходьбе.
5. **Страницы**: «Свойства» → «+ стр.», на второй странице добавить текст; на первой — кнопка с действием
   «страница» = `next`. Нажать — у вас вторая страница, у другого игрока — его своя.
6. **Двигать**: «Свойства» → «Двигать ✥»: панель за прицелом, колёсико — дальше/ближе, наведите на стрелку оси и
   тяните ЛКМ, Enter — поставить (редактор откроется снова), «Сохранить».
7. **Шаблоны**: «Шаблоны» → id `menu-1` → «Создать» у «меню с кнопками» → «Сохранить».
8. **Без OP**: J не открывает редактор; `/hoholo` недоступна; кнопки с условием «только OP» пишут «Нет доступа».
9. **Без мода**: голограмм не видно (так задумано).

## Пример для разработчиков модулей
```java
// module.yml: softdepends: [holo]; build.gradle.kts: compileOnly(project(":modules:holo"))
HoloApi holo = services().get(HoloApi.class).orElse(null);
if (holo != null) {
    holo.placeholder(id(), "fuel", 10, p -> String.valueOf(fuelOf(p)));       // {fuel}, раз в 0.5 с
    Hologram h = HoloApi.parse("""
        {"id": "dock-1", "map": "cosmos", "pos": [10, 70, 5], "theme": "amber", "pages": [{"lines": [
          [{"type": "text", "text": "<b>ДОК 1</b>", "size": 1.4}],
          [{"type": "bar", "value": "{fuel}", "max": 100, "label": "Топливо {fuel}%"}],
          [{"type": "button", "label": "Заправить", "left": [{"type": "cmd", "value": "refuel"}]}]]}]}""");
    holo.put(h, false);                                                          // временная: не в файл
    holo.onClick((p, hh, page, line, elem, right) -> { if (hh.id.equals("dock-1")) … });
}
// onDisable: holo.removePlaceholders(id()); holo.remove("dock-1"); holo.offClick(listener);
```

## Известные проблемы и ограничения
- В игре не проверялось (Minecraft на машине агента не запускается): возможны мелочи в отрисовке (порядок
  прозрачности фона и текста при пересечении двух голограмм, освещение предметов на панели), их видно только в игре.
- Колёсико в режиме «двигать» — через смену слота хотбара (крючка колёсика в ядре мода нет) — см. вопросы.
- Права `holo.view.<id>` / `perm:` — по умолчанию только OP (прав в ядре нет), см. вопросы.
- Шаблоны в превью PNG — данные-заглушки; в игре список приходит с сервера.
- Голограммы из кода (`HoloApi.put(h, false)`) в редакторе не правятся (их правит код) и в список не попадают.
- Переименовать голограмму нельзя — «Копия» с новым id + «Удалить».
