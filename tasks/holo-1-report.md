# Отчёт holo-1: голограммы на моде + редактор

Статус: в работе. Пункты по порядку.

## 1. Модель данных и сервер (`modules/holo`) — готово
- Модель `Hologram` (страницы → строки → ряд элементов: text, item, image, bar, button, separator, spacer; действия
  cmd/console/msg/sound/tp/ui/page по ЛКМ/ПКМ у любого элемента и у самой панели), JSON — `HoloCodec` (строгий разбор).
- Файлы `module/holo/holograms.json`, `templates.json` — атомарно, битый не перезаписывается (`HoloStore`).
- Плейсхолдеры: `Placeholders` — своя частота у каждого, считается на сервере на игрока, моду только изменившееся.
- Нажатия: `ClickGuard` — карта, видимость, расстояние, элемент, условие (OP/право), задержка; консоль — только у
  голограмм OP.
- Сервис `HoloApi`, команды `/hoholo` (`HoloCommand`), протокол — `Net`.
