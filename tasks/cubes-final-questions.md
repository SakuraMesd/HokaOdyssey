# Вопросы по задаче cubes-final

1. **Видимость сущностей по V (§4.8) — делать ли?** План: сущность видна игроку, только если |секция игрока − секция
   сущности| ≤ V. Не сделал: правило видимости в Minestom одно на сущность (`updateViewableRule`) и уже занято модулями
   (`ships` — якоря; чужие модули могут ставить своё), общее правило ядра их затрёт. И это спрячет корабль/игрока,
   который в 160+ блоках над/под тобой (V = 10 кубов). Если всё же нужно — предлагаю только для предметов и мобов
   (не игроков, не моделей кораблей), через тег-признак у сущности. Сейчас выбран самый безопасный вариант: не делать.

2. **Удаление старого кода (этап 7, §9) — после перевода карты `tall`?** Не удалял ничего: `TallChunk` нужен
   конвертеру и `CubeRegionLoader` (запасной источник .htw), его читает модуль `axiom`; `SodiumTallMixin` — основной путь
   Sodium и на кубовых картах. Список кандидатов и их связей — в отчёте. Когда `tall` переведена и проверена — можно
   отдельной задачей.

3. **Карта `tall` после перевода — сразу `cubes: true`?** Конвертер ставит только `store: cubes` (хранение регионами).
   Без `cubes: true` карта остаётся на старом tall-протоколе, но все кубы столбца держатся в памяти (`cube_lazy` только
   для кубовых карт). Рекомендую ставить `cubes: true` вместе с переводом (см. команды в отчёте).
