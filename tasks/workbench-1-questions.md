# Вопросы по workbench-1

1. **Крафт на верстаке.** В Minestom нет рецептов; окно `workbench` сейчас только с заголовком и «Закрыть». Что
   должен делать верстак: свои рецепты в config (вход → выход), сборка частей кораблей, улучшение предметов?
   Другие модули уже могут подключиться через событие `HoBlockUseEvent` (blocks) — без правок модуля blocks.
   *Сделано самое безопасное: только окно и событие.*
2. **Выпадение в выживании.** Сейчас как у остальных своих блоков: предмет сразу в инвентарь. Нужно ли выпадение
   предметом на землю / зависимость от инструмента (mining `drops_as`)?
3. **Анимация вдали.** Сейчас ≤48 — анимация, 48…64 — поза по умолчанию (кадровое рисование), дальше — только
   неподвижные кости из меша. Если нужно, чтобы вдали была видна вся модель, — либо увеличить радиус поиска (дороже),
   либо класть полную позу в меш и прятать её при приближении (нужна пересборка секций). Устраивает ли так?
