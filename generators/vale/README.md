# Генератор `vale` v3 — горы, хребты, разломы, великаны, рудные валуны

Переносимый генератор (сервер + мод Hoka Odyssey, ядро 0.60+), id `vale`, версия 3, высоты −500…2000, море 300.
v2 заменяет v1 (тот же id): рельеф другой, клиенты перекачивают jar по версии; карту v1 — перегенерировать.

**v3** (рельеф как в v2, объекты другие — карту заново, шаблон `map.yml.example` — карта HOKA23, папка `maps/hoka23` строчными):
- листва в мир — естественная: `persistent=false` и ванильная `distance` (шаги по листве до бревна объекта; дальние
  места кроны подпираются скрытой древесиной породы внутри кроны, остаток — distance=7, наш сервер листву не роняет).
  Раньше ставилась `persistent=true` — а эти состояния модуль `blocks` раздаёт носителями своих прозрачных блоков:
  `acacia_leaves[distance=1,persistent=true,waterlogged=false]` — первый по алфавиту носитель, его занял блок «Ступка»
  (`mortar`), и у игроков с модом кроны акаций/баобабов/зонтичных деревьев рисовались ступками;
- рудные валуны (уголь, железо, медь) — см. ниже.

## Рельеф (`Terrain`)
Карта высот без навесов (подсказки hasBlocks/uniform/highest точные). Только + − × /, floor, abs, `StrictMath.sqrt`.
Медленные поля (континенты, климат, искажение, пояса, маски) — в узлах сетки 4×4 блока, между ними билинейно.

| Ярус | Высоты | Чем |
|---|---|---|
| дно моря и озёр | ~225–299 | континентальность < 0, озёра |
| равнины, луга | 300–360 | континенты + мелкий шум |
| холмы | 340–480 | холмы, амплитуда 40–120 пятнами |
| предгорья | 450–850 | край пояса хребтов |
| средние горы, плато | 800–1200 | пояс + террасы-обрывы (ступени 8–48); тепуи 760–1060 с отвесными стенами |
| хребты и пики | 1200–1950 | ridged multifractal (Масгрейв) в центре пояса, мягкий потолок 1950 |
| разломы | на 150–700 ниже соседей | узкая извилистая трещина с плоским дном (сухо, базальт, магма, лужи лавы) |
| реки | дно 297 | узкая полоса на низинах (до 450) |

Пояса хребтов извилистые (искажение координат + поворот 30°), между ними 3–8 км равнин. Снеговая линия ~1150±60,
ледники выше 1250 (паковый лёд 3–8 с жилами голубого), выше 1600 — снег везде, кроме стен. На открытых стенах —
слои пород полосами по 7 блоков (камень/андезит/туф/кальцит/капельник; в мезах — терракоты; в разломах — туф/сланец/базальт).
Выборка 32×32 км (сид 20261126): максимум ~1870, выше 1500 — ~2 % колонок, вода ~30 %.

## Зоны (биомы MC — цвет травы и листвы)
ocean, beach, river, lake; plains, meadow, flower_forest, forest, birch_forest, taiga; **old_growth_spruce_taiga** (роща
великанов), **cherry_grove**, **mangrove_swamp** (топи), **mushroom_fields** (светогрибная чаща), **savanna_plateau**,
**wooded_badlands** (мезы), **jungle** (тропики), **pale_garden** (сумеречный лес), meadow/grove (альпика 720–1150),
jagged/stony/frozen_peaks, stony_shore (разломы). Климат — температура/влажность (шкала ~2.3 км) + «волшебные» пятна.

## Объекты
Процедурные (строит vale, `Flora`; по ячейкам, детерминированно, кэш по ячейке; каждый разный):
- деревья: секвойя-великан 70–150 (ствол до 5×5, корни-контрфорсы, грибы-полки), ель-пагода 35–70, тропический гигант
  50–95 (корни-доски, лианы до земли, какао; иногда пара с провисшим мостом-лианой), баобаб, зонтичная акация, драконово
  дерево, сакура-великан (ковёр лепестков), плакучая ива (шторы листвы и мох), мангр на ходулях, призрачный дуб
  (бороды бледного мха), «леденец»-спираль (редкий сюрприз на любой суше);
- грибы: колокол-светоносец (светильники и ягодные лианы под шляпкой), медузогриб (щупальца-лианы), гриб-пагода,
  пузырь-аметист;
- цветы-великаны: подсолнух (диск наклонён к югу), тюльпан, ромашка; кувшинка-великан на воде топей;
- рудные валуны (v3): 3–9 блоков, вкопаны на 35–55 %, 2–4 слитых бугристых эллипсоида (каждый свой), камень/андезит/
  туф/булыжник (во влажных лесах сверху мшистый булыжник), руда гнёздами у поверхности + вкрапления; уголь чаще всего,
  железо — горы и предгорья, медь — саванна, мезы и у воды (16 блоков); в горах и выше 650 — глубинный сланец, глубинная
  руда, иногда сырой блок железа/меди или угольный блок. Ячейка 36, плотность по зонам (горы 0.45–0.6, саванна/мезы
  0.4–0.45, равнины 0.22, леса 0.12–0.3).

`.hobj` из `objects/` (исходники — `demo-objects/`, пишет тест `ValeGenTest.writeDemoObjects` из `ValeDemoObjects`):
`oak`, `birch`, `spruce`, `bushes`, `rocks` (v1), `glycine` (8), `azure` (6, лазурные светящиеся), `palm` (6, тёплые пляжи),
`glowfingers` (6, светогрибы и дно разломов), `bellflowers` (6), `rafflesia` (5, джунгли).
Одиночные растения — в 2–3 раза гуще v1 и свои в каждой зоне (папоротники, сухая трава, кактусы с цветками,
лепестки сакуры, опавшие листья, светлячковые кусты, бледный мох, кувшинки); светящийся лишайник на стенах разломов.

Растительности нет на стенах (уклон ≥ 6), в 8 блоках от разлома и выше 1250. Лимит объекта: ≤ 64 по X/Z, ≤ 256 по Y.

Живучесть по ванильным правилам (тест ValeGenTest.vanillaSurvival): каждый объект (процедурный и .hobj) при сборке снимает
растения без опоры — лиана держится за полную грань сбоку или за лиану сверху, ягодные/плакучие лозы и спороцвет — только под
прочным блоком (листва не годится), бледный мох — под любой полной гранью, вьюны — на прочном снизу, какао — на джунглевом
бревне. Кактус — только на ровном и через клетку. Сухой разлом ниже моря рядом с водой поднимается до уровня моря (иначе
вода стоит стеной). Объекты .hobj с replace_all/keep_air или блок-сущностями вставляются как есть (без снятия опор).

## Честные подсказки и скорость
hasBlocks/uniform — по кэшу колонок (минимум/максимум по рамке 18×18) и охвату объектов колонки чанка; highest — по
блокам объектов колонки (первый записавший), растениям и флагам блоков (`Flags`; сверка с ядром — тест `flagsMatchCore`).
Скорость (`ValeGenTest.speed`, участки подряд): ~0.19–0.23 мс на куб против 0.11–0.15 у v1 (кубов на колонку больше — горы).

Сборка: `gradle :generators:vale:build` → `run/generators/vale.jar`. Карта — `map.yml.example`.
generator_options: `sea_level` (300), `tree_density` (1.0, 0…2).

**Важно для игрока:** клиент рисует окно ±VerticalView кубов (по умолчанию 10 = ±160 блоков, максимум 32 = ±512) —
пики 1500+ с равнины целиком не видны. Нужно несимметричное окно вверх до верха колонки или дальний горизонт (LOD).
