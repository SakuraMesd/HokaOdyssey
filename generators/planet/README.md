# Генератор `planet` v1

Переносимый генератор планеты: один jar работает и на сервере, и в моде Hoka Odyssey (ядро **0.60+**).

- Высоты **−500…2000**, уровень моря **300** (`generator_options.sea_level`).
- Рельеф пока **заглушка**: бедрок на дне, камень, 3 слоя земли, трава на уровне моря. Настоящий рельеф будет позже.
- Объекты (деревья, камни…) берутся из библиотеки `objects/` сервера. Их сохраняют командой `/hoobj` и расставляют сетками `FeatureGrid`.

## Сборка

`gradle :generators:planet:build` собирает `run/generators/planet.jar`. На сервер jar кладётся в папку `generators/`.

## Карта

Скопировать `map.yml.example` в `maps/<имя>/map.yml`, затем `/homap tp <имя>`.

| Ключ | Смысл |
|---|---|
| `objects:` | Категории из `objects/`, `"*"` — все. Нет ключа — все категории. |
| `generator_options.sea_level` | Уровень моря (300). |
| `generator_options.features` | Список сеток `{category, cell, density, margin, salt}`. По умолчанию `trees`, cell 12, density 0.35, margin 2. |

- `cell` — размер ячейки. В каждой ячейке не больше одного объекта.
- `density` — доля ячеек, в которых стоит объект.
- `margin` — отступ объекта от края ячейки.

## Как добавить объект в генерацию

1. Построить объект, например дерево.
2. Выделить его: `/hoobj pos1` и `/hoobj pos2` (блок под прицелом или `feet`).
3. Сохранить: `/hoobj save trees/oak1`. Якорь по умолчанию — центр-низ. С опцией `feet` якорь берётся в ногах. Воздух не сохраняется.
4. Настроить: `/hoobj set trees/oak1 weight 2`, `on grass_block`, `sink 1` и т.д. Значения хранятся в `objects/trees/oak1.json`.
5. Перезагрузить карту: `/homap unload <карта>`, затем `/homap tp <карта>`. Пакет объектов фиксируется при загрузке карты. `/hoobj pack` показывает, совпадает ли он с диском.

Нетронутые кубы сгенерируются уже с новыми объектами, правки игроков останутся. После смены объектов индекс pregen устаревает, его нужно пересоздать: `/hocubes pregen`.
